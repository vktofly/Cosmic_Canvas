# ADR 001: Multi-Scale Cosmic Object Comparison Engine

## Status
Approved

## Context
Understanding the scale of astrophysical bodies (Neutron Star vs. Stellar Black Hole vs. Supermassive Black Hole vs. TON 618 vs. Solar System) requires visual proportional comparison.

## Decisions Made
1. **Visual Paradigm**: Direct 3D Side-by-Side proportional meshes (Earth, Sun, Solar System Orbit).
2. **Catalog Scope**: Terrestrial/Stellar (Earth, Sun, Planetary Orbits) scaling relative to the active Schwarzschild Event Horizon.
3. **Photon Dynamic Geodesics**: Dynamic photon beam pulses that travel, bend continuously through warped spacetime, and vanish into the event horizon ($r < 1.45 M$).
